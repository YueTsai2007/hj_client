# 变更记录

## 2026-11 作战视图 v3 阶段

### 新增功能

- **作战视图**：16:9 letterbox 舞台 + 四角 HUD（基地/前哨/双方机体血条/计时/本机/小地图/事件条），HUD 按画面宽度整组缩放不重排；`F3` 与数据视图互切。
- **数据视图重排**：左列地图 + 左下事件/即时战术数据，右列双方机器人 + 右下图传；顶部状态条（前哨/经济/堡垒/买活）。
- **地图**：改用规则手册图 4-1 官方渲染图作底图（压暗、降饱和），自己绿色、全部机体带编号、血条、朝向箭头。
- **兑换/买活面板**（`O`）：按 `--id` 自动 17mm / 42mm，数量 10 倍数校验，客户端上行 `CommonCommand`；买活按钮（cmd_type 待协议核对）。
- **机制提示条**：`GlobalSpecialMechanism` 有生效机制时出现，按协议官方枚举翻译（1 己方堡垒被激活、2 对方堡垒被激活、3 R 前哨阵地、4 B 前哨阵地、5 R 基地阵地、6 B 基地阵地），3–6 按符号显示己方/对方推进。
- **模块自检**：`RobotModuleStatus` 8 个模块绿/红点。
- **准星**（`F4`）：可开关并记忆。
- **地图镜像**：地图下方勾选框，整幅底图与标记一起镜像，状态记忆。

### 变更

- **刷新方式**：由固定定时器轮询改为**收到下行消息即刷新**（同一轮事件循环合并），定时器只负责过期判断。
- **过期阈值**：集中到 `client/topics.h`，按协议表 1-5 的实际发送频率分类（1Hz → 3s、3Hz → 1.5s、10Hz → 0.8s、雷达 ≤5Hz → 1.2s、触发式 → 3s）。
- **坐标**：协议 0x0203 为米，原点红方补给站角、X 向蓝方、Y 向红方停机坪；换算集中在 `client/field.h`，地图用几何映射 `(20,11) 860×460 ⇔ 28m×15m`。
- **校准**：保留 `HJ_MAP_CAL_X/Y/W/H`（平移 + 宽高修正），用于场地公差与底图裁切误差，默认 0。
- 移除作战视图中的"第几局""比赛中"等冗余文字；伤害拆解因无法归因兵种而删除。

### 修复

- **HUD 启动崩溃**：`findChildren<HudCard*>` 在类未声明 `Q_OBJECT` 时产生非法指针（ASan 定位为堆越界），改为按注册表遍历卡片。
- **HUD 字号被全局样式覆盖**：全局 QSS 的 `QWidget{font-size:16px}` 会压过 `setFont`，改为控件级样式表下发字号。
- **蓝方配色错乱**：己方血条/名称/前哨/控制度仍显示红色或金色；统一由 `allyAccent`/`enemyAccent` 派生，金色只留中性 UI。
- **蓝方阵营判断**：`base_health`/`enemy_base_health` 本身是"己方/敌方"相对字段，之前按阵营翻转导致基地显示互换；仅 `outpost_R/B` 需要翻转。
- **截图尺寸异常**：全屏与非全屏状态混用导致离屏抓图变 800×600，抓图前强制 `showNormal + resize`。
- **顶部金色提示条常驻**：改为机制提示条，无机制时隐藏。
- **地图标记不可读**：小地图上编号被隐藏、标记过大；改为尺寸自适应画布、编号恒 ≥8px 白字加阴影。
- **魔法系数**：`820/430` 手调系数改为协议推导的几何映射。
